# Code citations (Cursor IDE)

When referencing existing code in the editor:

- Use `startLine:endLine:filepath` format in fenced code blocks
- Citation fences must be on their own line, never prefixed by list markers
- Inside citations, skip large irrelevant chunks with `...` or brief comments
- Inline backticks and fenced blocks show content literally — no HTML entities
